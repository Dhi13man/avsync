# Governance

AV Sync Lab uses a maintainer-led governance model.

## Roles

| Role | Responsibility |
| ---- | -------------- |
| Maintainer | Sets direction, reviews changes, manages releases, and enforces conduct |
| Contributor | Reports bugs, proposes features, submits pull requests, and improves docs |
| User | Provides feedback and real-world sync cases when possible |

## Decision making

The maintainer makes final decisions after considering user impact, project
scope, implementation risk, and maintenance cost.

Changes that affect sync correctness, export behavior, security posture, or
public API expectations need a clear rationale and verification notes.

## Release ownership

Only maintainers publish releases and tags. Release steps are documented in
[docs/RELEASE.md](docs/RELEASE.md).
